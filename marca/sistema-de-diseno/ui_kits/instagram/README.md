# UI kit — Instagram carousel

The brand's publishing surface: @loreflorezb posts multi-slide carousels that teach one
idea and route to a booking link in bio. Source: `uploads/GUÍAS LF.pdf`
("SALMO 121 · GUÍA PRÁCTICA", 4 pages, Canva), reflowed onto the 1080×1080 canvas the
brand posts at.

## Slides

| Slide | Role |
|---|---|
| `TitleSlide` | Big number/title, sticker label, one-line promise, heart illustration |
| `WhySlide` | Framing paragraph plus the thesis as a pull quote |
| `VerseSlide` | One verse, one metaphor, explained in plain language |
| `TwoWaysSlide` | The "quien sufre / quien acompaña" two-column split |
| `StepsSlide` | Three concrete steps as a heart-bulleted list, closing scripture |
| `PrayerSlide` | Prayer card + booking CTA |

## Notes

- `index.html` frames the slides in a simplified Instagram post (header, action row, dots,
  caption) so the crop and type sizes can be judged in context. Click the image to advance.
- Type scale on the square canvas: title 128px, headline 70–82px, body 34–40px,
  signature 24px. Nothing below 28px.
- Slide count in the real posts is 6–10; the last slide is always the CTA.
- The frame chrome is a plain recreation for context, not part of the design system.
