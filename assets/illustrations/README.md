# Ilustraciones

Vienen del sistema de diseño «Lore Flórez Design System». Estilo (manual §07): plano con grano, rosas cálidos, ojos cerrados; recortes vintage en blanco y negro solo en collage.

| Archivo | Qué es | Dónde usarla |
|---|---|---|
| `hearts-armchairs.png` | Dos corazones en sillones, uno con libreta: una sesión | Consulta, señales, invitación a agendar |
| `hearts-community.png` | Corazones alrededor de un corazón herido | Comunidad, acompañar, «no en soledad» |
| `heart-running.png` | Corazón feliz corriendo | Alivio, libertad, cierre esperanzador |
| `heart-arrows.png` | Corazón con flechas clavadas | **Serie «6 flechas»** |
| `eva-sticker.png` | Mujer de ojos cerrados con flecha, borde calcomanía | **Serie «6 flechas»** |
| `man-arms-crossed.png` | Hombre de brazos cruzados con flecha | **Serie «6 flechas»** |
| `woman-hands-face.png` | Recorte vintage, mujer con manos en la cara y flecha | **Serie «6 flechas»** |
| `star-8pt-blush/salmon/paper.png` | Estrella de 8 puntas tono sobre tono | Decoración (`.estrella`), la elige el fondo |
| `star-8pt-mask.png` | Silueta de la estrella | Máscara para la estrella sobre fondo tinta |
| `star-textured.png`, `star-outline.png` | Estrellas de las guías PDF | Guías, no carrusel |

La flecha de plumas rosadas es el motivo de la serie «6 flechas»: las ilustraciones que la llevan no se usan en otros temas.
Para una ilustración nueva, agrega el PNG con fondo transparente y súmalo a esta tabla. No se generan ilustraciones con IA.
